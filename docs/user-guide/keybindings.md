# Keybindings

## Main Screen

- `n`: new idea
- `e`: edit selected idea
- `d`: delete selected idea
- `g`: new group
- `Shift+G`: delete selected group
- `/`: focus search
- `Esc`: cancel search/back
- `Tab`: switch pane
- `Ctrl+B`: toggle list pane visibility
- `y`: copy body or selected text (context-sensitive)
- `?`: help
- `q`: quit

## Idea Form

- `Ctrl+S`: save
- `Esc`: cancel
